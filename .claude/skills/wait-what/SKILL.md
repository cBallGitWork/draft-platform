# Say it again, plainly

Craig didn't follow the last message. Re-pitch it; don't defend it.

1. Lead with the one thing he needs to know or decide, in one sentence.
2. Use the project's glossary words (`.studio/skills.md` names where it is), and the real world's
   own words for its subject.
3. No metaphor the message didn't need ("load-bearing", "seam", "frontier", "lands"). Name the
   file, the screen or the number instead.
4. Three to six short lines. If a choice is involved, list the options and your pick.
5. Add nothing new. If re-saying it shows the original was wrong, say that first.
