## Interaction notes

- **Guide** in the top bar: opens the Guide, underlined while it is open (S23.3).
- **Search the Guide**: typing replaces the sections with the matching entries, each under its
  section's name, with the count above; clearing it brings the sections back.
- **A section's row**: opens or folds it; the open one shows ▾, the others ▸.
- **Formations (24)** and **Classic sides (7)**: fold out to an entry for each, the same held
  description the formation window shows (S23.7).
- **An entry's row**: opens it on the right, the cyan bar marking it. Each entry has an address of
  its own, so a hover help can open it (S23.11, #2749).
- **The entry**: its section and title on the plate, then plain text (S23.9).
- **A link to the league**: where an entry touches a rule the league sets, its last line links to the
  league's Rules or League settings, never copying a number (S23.8).
