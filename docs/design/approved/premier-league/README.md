## The Football Manager idea

FM's competition screen: fixtures beside the table, with the qualification and relegation places
marked by lines. Its organisation, never its colours.

## Interaction notes

- **Competition tabs:** each switches the fixtures and the table to that competition. Only the
  competitions the league plays show.
- **◄ GW ►:** steps the fixtures a gameweek at a time. The page opens on the current gameweek.
- **A fixture:** opens its match page ([`premier-league-match`](../premier-league-match/README.md)).
- **Table lines:** hovering one says what it marks.
- **Arrows:** ▲ cyan up and ▼ orange down, with the number of places; "–" when a club hasn't moved.
  Hovering one says "Up 2 since GW11 began".
